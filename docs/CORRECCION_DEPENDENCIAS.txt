COMO INSTALAR AHORA
====================

OPCION 1 - AUTOMATICA (Recomendado)

Linux/Mac:
    bash run.sh

Windows:
    python run.sh

OPCION 2 - MANUAL (Si prefieres control)

1. Crea entorno:
    python -m venv venv

2. Activa (Linux/Mac):
    source venv/bin/activate
   
   O Activa (Windows):
    venv\Scripts\activate

3. Instala dependencias:
    pip install -r requirements.txt

4. Verifica:
    python test_setup.py

5. Ejecuta:
    python dgsp_agent.py

OPCION 3 - SI SIGUE FALLANDO

Lee INSTALACION_DETALLADA.txt sección "Problemas y Soluciones"
Tiene solución para cada error específico.
