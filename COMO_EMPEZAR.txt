TODO LO QUE NECESITAS SABER
============================

¿Qué es este agente?
Una IA que responde preguntas sobre la DGSP basándose 100%
en tu manual de organización. No inventa, no alucina.

¿Cómo funciona?
1. Tu pregunta se convierte en números (embeddings)
2. Busca en el manual los fragmentos más similares
3. Recupera conversaciones previas
4. Envía todo a Llama 3.1 de Groq
5. Devuelve respuesta precisa

¿Por qué no alucina?
Porque:
- Solo usa documentos que le das
- Tiene instrucciones explícitas de no inventar
- Temperatura baja = respuestas precisas
- Si no está en el PDF, lo dice claramente

¿Funciona sin internet?
- Después de primera carga: SÍ
- Solo necesita conectarse a Groq API
- El PDF se procesa localmente
- La memoria está en tu computadora

¿Es seguro?
- Tu PDF NO se envía a internet
- Todo se procesa localmente
- Base de datos SQLite en tu disco
- Vector store FAISS en tu disco

¿Qué datos se guardan?
- Preguntas que hiciste
- Respuestas del agente
- Timestamps
- Contexto de conversación
- TODO en tu máquina

¿Puedo ver los datos?
- Sí, están en agent_memory.db (SQLite)
- Puedes abrirlo con cualquier herramienta SQLite
- O usar Python para consultarlo

¿Puedo borrar datos?
- Sí, con el comando agent.delete_session()
- O borrando agent_memory.db completo

¿Puedo agregar más PDFs?
- SÍ, es una mejora recomendada
- Lee la sección en GUIA_EDUCATIVA.md

¿Puedo cambiar el LLM?
- SÍ, en lugar de Groq puedes usar OpenAI, Anthropic, etc.
- Lee GUIA_EDUCATIVA.md para detalles

PROBLEMAS COMUNES Y SOLUCIONES
===============================

Error: "GROQ_API_KEY not configured"
Causa: .env no tiene clave o está mal
Solución:
  1. Abre .env
  2. Verifica que GROQ_API_KEY=tu_clave (sin "tu_clave_aqui")
  3. Guarda
  4. Reinicia terminal
  5. Intenta de nuevo

Error: "FileNotFoundError: manual_dgsp.pdf"
Causa: El archivo no está en la carpeta correcta
Solución:
  1. Verifica que manual_dgsp.pdf esté en raíz
  2. Ejecuta: ls -la manual_dgsp.pdf
  3. Si no existe, cópialo: cp ruta/del/pdf ./manual_dgsp.pdf

Error: "ModuleNotFoundError: No module named 'langchain'"
Causa: Dependencias no instaladas
Solución:
  1. Ejecuta: pip install -r requirements.txt
  2. Espera a que termine
  3. Intenta de nuevo

Error: "Connection timeout to Groq API"
Causa: Problema de internet o API key inválida
Solución:
  1. Verifica tu conexión a internet
  2. Verifica tu API key en https://console.groq.com
  3. Si cambió, actualiza .env
  4. Intenta de nuevo

El agente es muy lento
Causa: Primera ejecución, está creando vector store
Solución:
  1. En la primera ejecución tarda 1-2 minutos
  2. Después es rápido (2-4 segundos por respuesta)
  3. La siguiente vez no habrá espera
